# 🛒 E-Commerce Sales & Customer Analytics Dashboard
### Brazilian Olist Dataset | Data Analyst Portfolio Project

---

## 📋 Project Overview

This project analyzes the **Brazilian E-Commerce Public Dataset by Olist** to uncover
business insights around sales performance, customer behavior, regional trends, and
delivery operations.

Built using **MySQL**, **Microsoft Excel**, and **Power BI** — the standard Data Analyst
toolkit for fresher interviews.

**Dataset Source:**  
[Kaggle — Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

*Note for presentation: Customer display names are anonymized to Indian-style names
(e.g., "Priya Sharma") for demo purposes. All original dataset values and
relationships are fully preserved.*

---

## ❓ Business Problem

An e-commerce business wants to answer these questions:

1. How is revenue trending month over month?
2. Which product categories and states drive the most revenue?
3. How many customers are one-time vs. repeat buyers?
4. Are orders being delivered on time? Which states face more delays?

## 📁 Dataset Tables Used

| Table | Key Columns | Purpose |
|-------|-------------|---------|
| `olist_orders_dataset` | order_id, customer_id, order_status, dates | Order lifecycle + delivery dates |
| `olist_order_items_dataset` | order_id, product_id, price, freight_value | Revenue per item |
| `olist_products_dataset` | product_id, product_category_name | Product category (Portuguese) |
| `olist_customers_dataset` | customer_id, customer_unique_id, customer_state | Who bought, from where |
| `product_category_name_translation` | product_category_name, product_category_name_english | Portuguese → English |

> **Key concept:** A customer gets a NEW `customer_id` with every order, but their
> `customer_unique_id` stays the same. Always use `customer_unique_id` for
> repeat customer analysis.

## 🧹 Data Cleaning Summary

### What was cleaned:
| Step | Action | Why |
|------|--------|-----|
| 1 | Filter `order_status = 'delivered'` | Only count completed orders |
| 2 | Drop rows with NULL delivery dates | Can't calculate delay without both dates |
| 3 | Merge 5 tables into one master CSV | Easier to use in Excel and Power BI |
| 4 | Add `total_item_value` = price + freight | What the customer actually paid |
| 5 | Add `delivery_time_days` | Days from purchase to delivery |
| 6 | Add `is_delayed` flag | True if actual delivery > estimated date |
| 7 | Add `delay_days` | How many days late (0 if on time) |
| 8 | Add `order_month` (YYYY-MM) | For monthly trend charts |
| 9 | Fill missing English category names | Fallback to Portuguese if no translation |
| 10 | Add `display_name` (Indian-style names) | Presentation anonymization only |

> **SQL handles all of this via JOINs and CASE statements.**  
> Python only pre-merges CSVs — it's completely optional.

## 💡 Key Business Insights

*(Approximate values based on Olist dataset — exact numbers appear after loading data)*

1. **São Paulo dominates** — SP state accounts for ~40%+ of all orders and revenue
2. **Health & Beauty is the top category** — consistently highest revenue category
3. **97%+ customers buy only once** — repeat purchase rate is extremely low (~2-3%)
4. **Peak in Nov 2017** — likely Black Friday; highest single-month revenue spike
5. **Average delivery is ~12 days** — very long; cities far from SP take even longer
6. **~8-10% orders are delayed** — northern/remote states face significantly more delays
7. **Average Order Value ~R$155-170** — includes price + freight per order

## ▶️ How to Run This Project

### Step 1 — Get the Dataset
```
→ Go to: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
→ Download all CSVs
→ Place the 5 required CSV files inside data/raw/
```

### Step 2 — MySQL Setup
```sql
-- In MySQL Workbench:
-- 1. Run sql/01_schema.sql   (creates database + tables)
-- 2. Right-click each table → Table Data Import Wizard → select CSV from data/raw/
--    Import ORDER: customers → products → category_translation → orders → order_items
-- 3. Run sql/02_queries.sql  (all business queries)
```

### Step 3 — Python Cleaning (Optional)
```bash
pip install pandas
python python/data_cleaning.py
# Output saved to: data/cleaned/olist_cleaned_master.csv
```

### Step 4 — Excel
```
→ Open data/cleaned/olist_cleaned_master.csv in Excel
→ Follow docs/EXCEL_GUIDE.md step by step
```

### Step 5 — Power BI
```
→ Open Power BI Desktop (free download from Microsoft)
→ Get Data → Text/CSV → select olist_cleaned_master.csv
→ Follow docs/POWERBI_GUIDE.md step by step
```
